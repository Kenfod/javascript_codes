Nested Objects

       Nested objects in JavaScript are simply objects contained within other objects. They allow you to build complex data structures, group related data logically, and represent real-world hierarchies like user profiles, product catalogs, or API responses.

       
1. Creating a Nested Object

As agreed by the developer community on Stack Overflow, using object literal notation (curly braces {}) is the most straightforward and common way to define a nested structure.

const user = {
  id: 101,
  name: "Spongebob Squarepants",
  // Nested Object
  address: {
    street: "124 Conch Street",
    city: "Bikini Bottom",
    zipCode: 12345
  },
  // Nested Object within an Array
  preferences: {
    theme: "dark",
    notifications: {
      email: true,
      sms: false
    }
  }
};


2. Accessing Nested Properties

You can access nested data using either dot notation or bracket notation.


Method	Syntax Example	Best Used For
Dot Notation	user.address.city	Standard, clean syntax when you know the key name directly.
Bracket Notation	user["address"]["city"]	Dynamic keys, variables, or keys with spaces/special characters.


Avoiding the TypeError crash: Optional Chaining (?.)

If you try to read a deep property from an object or path that doesn't exist (e.g., user.contact.phone), JavaScript throws a fatal error. Use optional chaining (?.) to safely return undefined instead of crashing your app.

// Safe access: if 'contact' doesn't exist, it evaluates to undefined safely
console.log(user.contact?.phone); 


3. Modifying and Adding Properties

You can update values or append new structures down the chain using assignment operators (=)

// Modifying an existing nested value
user.address.city = "Rock Bottom";

// Adding a completely new nested property
user.address.coordinates = {
  lat: 12.456,
  lng: -84.212
};


4. Cloning & the Deep Copy Gotcha

A common pitfall with nested objects is shallow copying. Built-in mechanisms like the spread operator (...) or Object.assign() only copy the first level of data. If you change a nested object in the copy, it will modify the original object as well.

// ❌ Shallow copy pitfall
const shallowCopy = { ...user };
shallowCopy.address.city = "New City"; 
// WARNING: user.address.city is now also "New City"!

//  Deep copy solutions
const deepCopy1 = structuredClone(user); // Native modern JS method
const deepCopy2 = JSON.parse(JSON.stringify(user)); // Older legacy alternative
