Arrays and Objects


  
       In JavaScript, an array of objects combines an ordered list (array) with structured key-value pairs (objects). 
       This is the most common format for managing real-world data like user profiles, shopping carts, or product catalogs.

1. Creation and Syntax

You define an array using square brackets [] and populate it with objects wrapped in curly braces {}.

const users = [
  { id: 1, name: "Sarah", age: 22, isActive: true },
  { id: 2, name: "James", age: 30, isActive: false },
  { id: 3, name: "Lena", age: 27, isActive: true }
];

2. Accessing and Modifying Data

To access a property, chain the array index number with the object's key name using dot notation.
• Read a value: users[0].name returns "Sarah".
• Update a value: users[1].age = 31; updates James's age.
• Add a new object: Use .push() to append to the end.

users.push({ id: 4, name: "Alex", age: 25, isActive: true });

3. Essential Array Methods

JavaScript provides powerful built-in methods designed to search, filter, and transform arrays of objects without manual for loops.

🔍 Searching & Filtering

• .filter(): Returns a new array containing all objects matching a condition.

const activeUsers = users.filter(user => user.isActive);

// Returns Sarah and Lena's objects

.find(): Returns only the first object that meets a condition.

const james = users.find(user => user.name === "James");

// Returns { id: 2, name: "James", age: 31, isActive: false }

🛠️ Transforming Data
• .map(): Creates a new array by extracting or transforming properties from each object.

const namesOnly = users.map(user => user.name);

// Returns ["Sarah", "James", "Lena"]

.reduce(): Condenses the array into a single value (like a sum, average, or unified object).

const totalAge = users.reduce((sum, user) => sum + user.age, 0);
// Returns 80

🔄 Iterating & Sorting

• .forEach(): Loops through every object to perform actions (like logging or updating UI).

users.forEach(user => console.log(`${user.name} is ${user.age} years old.`));

• .sort(): Sorts the objects based on a property comparison.

// Sort users by age (youngest to oldest)

users.sort((a, b) => a.age - b.age);

⚠️ Common Mistake to Avoid

Do not use direct equality comparisons (===) on objects.
In JavaScript, objects are compared by memory reference, not by value.

// ❌ This will return undefined even if the user exists
const found = users.find(user => user === { id: 1, name: "Sarah", age: 22, isActive: true });

//  This works perfectly
const foundCorrectly = users.find(user => user.id === 1);
