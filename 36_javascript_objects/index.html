Javascript objects

      A JavaScript object is a fundamental data structure used to store collections of related data and functionality. 
      It is a non-primitive data type that allows for the organization of data into key-value pairs.

      Key characteristics of JavaScript objects:
      
       1. Key-value pairs (Properties):
      Objects store data as properties, where each property consists of a unique key (a string or Symbol) and an associated value. 
      The value can be any JavaScript data type, including other objects, primitive values (strings, numbers, booleans, null, undefined, Symbol), or functions.

      2. Methods:
      When the value of a property is a function, it is referred to as a method. 
      Methods define actions or behaviors associated with the object.
      
      3. Dynamic nature:
      Objects are dynamic, meaning properties can be added, modified, or deleted after the object has been created.
      
      4. Reference values:
      Objects are reference values, meaning that when an object is assigned to a variable or passed as an argument to a function, 
      a reference to the object's location in memory is used, rather than a copy of the object itself.
      
      Creating JavaScript Objects:
      There are several ways to create JavaScript objects:
      
      1. Object Literal (Initializer Syntax): 
      This is the most common and concise way to create objects.
                const person = {
                    firstName: "John",
                    lastName: "Doe",
                    age: 30,
                    greet: function() {
                        console.log("Hello!");
                    }
                };
      
      2. Using the Object() Constructor.

                const car = new Object();
                    car.make = "Toyota";
                    car.model = "Camry";

      3.Using Constructor Functions: For creating multiple similar objects.

                function Person(name, age) {
                    this.name = name;
                    this.age = age;
                }
                const person1 = new Person("Alice", 25);

      4. Using Object.create(): For creating new objects with a specified prototype object.

                const protoObject = {
                    sayHi: function() {
                        console.log("Hi!");
                    }
                };
                const anotherObject = Object.create(protoObject);

      Accessing Object Properties and Methods:
      
      Properties and methods can be accessed using dot notation or bracket notation:
      Dot notation: objectName.propertyName or objectName.methodName()
      Bracket notation: `objectName'propertyName']` or `objectName['methodName'
