Class

       JavaScript classes, introduced in ES6 (ECMAScript 2015), 
       provide a more structured and object-oriented way to create objects with shared properties and methods. 
       While JavaScript is fundamentally a prototype-based language, 
       classes offer a syntactic sugar that makes object-oriented programming patterns more intuitive and similar to other class-based languages like Java or C++. 

      Key aspects of JavaScript classes:
      1. Syntax: 
      Classes are declared using the class keyword, followed by the class name.

            class MyClass {
              // Class members go here
            }

      2. Constructor: 
      The constructor() method is a special method within a class that is automatically 
      called when a new instance of the class is created using the new keyword. 
      It is used to initialize the object's properties. 

            class Person {
              constructor(name, age) {
                this.name = name;
                this.age = age;
              }
            }

      3. Methods: 
      Methods are functions defined within a class that provide behavior for objects created from that class.

            class Person {
              constructor(name, age) {
                this.name = name;
                this.age = age;
              }

              greet() {
                console.log(`Hello, my name is ${this.name} and I am ${this.age} years old.`);
              }
            }

      4. Instance Creation: 
      New objects (instances) are created from a class using the new keyword.

            const person1 = new Person("Alice", 30);
            person1.greet(); // Output: Hello, my name is Alice and I am 30 years old.

      5. Inheritance: 
      Classes support inheritance using the extends keyword, allowing a child class to inherit properties and methods from a parent class. 
      The super() method is used in the child class's constructor to call the parent's constructor.

            class Student extends Person {
              constructor(name, age, studentId) {
                super(name, age); // Call parent constructor
                this.studentId = studentId;
              }
            }

      6. Encapsulation (Private Elements): 
      JavaScript classes support private class fields and methods using the # prefix, 
      which ensures that these elements cannot be accessed or modified from outside the class, promoting encapsulation.

            class MyClass {
              #privateField = "I am private";

              #privateMethod() {
                console.log("This is a private method.");
              }

              publicMethod() {
                this.#privateMethod();
                console.log(this.#privateField);
              }
            }
