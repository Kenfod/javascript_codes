Destructuring

       JavaScript destructuring is a convenient syntax introduced in ES6 that allows you to unpack values from arrays or properties from objects directly into distinct variables. 
       It eliminates repetitive code and makes your scripts significantly cleaner.

       Object Destructuring:
       Object destructuring matches variables by their property keys.
       
       Basic Extraction:
       Extract properties directly into variables with matching names.

       const user = { name: "Alice", age: 25 };

      // Unpacking properties
      const { name, age } = user;

      console.log(name); // "Alice"
      console.log(age);  // 25

      Renaming Variables:
      Assign properties to variables with completely different names using a colon (:):

      const { name: userName, age: userAge } = user;
      console.log(userName); // "Alice"

      Default Values:
      Provide fallback values in case a property is undefined:

      const { role = "guest" } = user;
      console.log(role); // "guest"

      Array Destructuring:
      Array destructuring maps variables based on the index order of elements.
      
      Basic Extraction:

      const colors = ["red", "green", "blue"];

      // Unpacking by order
      const [firstColor, secondColor] = colors;

      console.log(firstColor);  // "red"
      console.log(secondColor); // "green"

      Skipping Elements:
      Skip unwanted items by leaving blank spaces between commas:

      const [primary, , tertiary] = colors;
      console.log(tertiary); // "blue"

      Advanced Techniques:
      The Rest Syntax (...)
      Collect the remaining unpackaged properties or array elements into a new container.

      // With Objects
      const { name, ...restOfProperties } = user; 

      // With Arrays
      const [first, ...restOfElements] = colors; 

      Function Parameter Destructuring:
      Unpack properties right inside a function signature to bypass manual reference points.

      function greet({ name, age }) {
        console.log(`Hello ${name}, you are ${age}.`);
      }

      greet(user); // "Hello Alice, you are 25."

      Nested Destructuring:
      Extract deeply embedded data structures in a single step.

      const metadata = { id: 1, data: { size: 400, type: "png" } };

      const { data: { size, type } } = metadata;
      console.log(size); // 400

      ⚠️ Critical Fail Safes:
      Destructuring null or undefined instantly throws a TypeError.
      Always pair nested extractions with fallback values if the parent object might be missing: 
      
      const { data: { size } = {} } = metadata || {};.
