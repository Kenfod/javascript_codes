Super Keyword

      The super keyword in JavaScript is used within classes to refer to the parent class (or superclass). 
      It serves two primary purposes:

      1. Calling the parent class's constructor: In a subclass, when you define a constructor method, you must call super() before using this. 
      This ensures that the parent class's constructor is executed and its properties are properly initialized on the instance. 

                class Animal {
                  constructor(name) {
                    this.name = name;
                  }
                }

                class Dog extends Animal {
                  constructor(name, breed) {
                    super(name); // Calls the Animal constructor
                    this.breed = breed;
                  }
                }

                const myDog = new Dog("Buddy", "Golden Retriever");
                console.log(myDog.name); // Output: Buddy
                console.log(myDog.breed); // Output: Golden Retriever

      2. Accessing parent class methods and properties: You can use super followed by a dot (.) 
      and the method or property name to call methods or access properties defined in the parent class. 
      This is particularly useful for method overriding, where you want to extend the parent's functionality rather than completely replace it.

                    class Animal {
                      speak() {
                        console.log("Animal makes a sound.");
                      }
                    }

                    class Dog extends Animal {
                      speak() {
                        super.speak(); // Calls the Animal's speak method
                        console.log("Dog barks.");
                      }
                    }

                    const myDog = new Dog();
                    myDog.speak();
                    // Output:
                    // Animal makes a sound.
                    // Dog barks.

      In essence, super provides a way to interact with the parent class within the context of a subclass, 
      facilitating inheritance and allowing for the extension and modification of parent class behavior.
