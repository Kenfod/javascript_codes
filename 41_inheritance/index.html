Inheritance

       JavaScript implements inheritance primarily through two mechanisms: prototypal inheritance and class-based inheritance (introduced in ES6).

        1. Prototypal Inheritance:
        Core Concept:
        JavaScript is fundamentally a prototype-based language. 
        This means objects inherit properties and methods directly from other objects, 
        rather than from classes as in traditional object-oriented programming languages like Java or C++.
        
        Prototype Chain:
        Every JavaScript object has an internal link to another object called its prototype. 
        When you try to access a property or method on an object, JavaScript first looks for it on the object itself. 
        If not found, it traverses up the "prototype chain" to the object's prototype, 
        then to that prototype's prototype, and so on, until the property is found or the end of the chain (null) is reached. 
        
        Creating Inheritance:
        You can achieve prototypal inheritance by setting the prototype of one object to another. 
        For example, Child.prototype = Object.create(Parent.prototype); sets up the inheritance link.
        
        2. Class-Based Inheritance (ES6 and later):
        Syntactic Sugar:
        ES6 introduced the class keyword, which provides a more familiar syntax for object-oriented programming, 
        but it's still built on top of the existing prototypal inheritance model. 
        Classes are essentially "syntactic sugar" for constructor functions and prototypes.
        
        extends Keyword:
        To achieve inheritance with classes, you use the extends keyword. 
        A child class extends a parent class, inheriting its properties and methods.

                  class Parent {
                      constructor(name) {
                          this.name = name;
                      }
                      greet() {
                          console.log(`Hello, ${this.name}`);
                      }
                  }

                  class Child extends Parent {
                      constructor(name, age) {
                          super(name); // Calls the parent class constructor
                          this.age = age;
                      }
                      introduce() {
                          console.log(`My name is ${this.name} and I am ${this.age} years old.`);
                      }
                  }

                  let myChild = new Child("Alice", 10);
                  myChild.greet(); // Inherited from Parent
                  myChild.introduce();

      super Keyword: The super keyword is used within a child class to refer to the parent class. 
      super(): Calls the parent class's constructor, crucial for initializing inherited properties.
      super.methodName(): Calls a method from the parent class.

      In summary, JavaScript offers a flexible approach to inheritance, 
      leveraging its unique prototypal nature while providing a more conventional class-based syntax for easier development.
