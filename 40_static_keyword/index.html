Static Keyword

       In JavaScript, the static keyword is used within a class definition to declare static methods or static fields. 
       Static members belong to the class itself, rather than to any individual instance of that class.

        Key characteristics of static members:
        1. Class-level scope: 
        Static methods and fields are accessed directly on the class name, not on instances created from the class.

                  class MyClass {
                    static staticField = "I am a static field";
                    static staticMethod() {
                      return "I am a static method";
                    }
                  }

                  console.log(MyClass.staticField); // Output: I am a static field
                  console.log(MyClass.staticMethod()); // Output: I am a static method

                  const instance = new MyClass();
                  console.log(instance.staticField); // Output: undefined (cannot access on instance)
                  // instance.staticMethod(); // This would result in an error

          2. No instance context:
          Static methods do not have access to this in the context of an instance. 
          They operate independently of any specific object created from the class.
          
          3. Utility functions and shared data:
          Static methods are commonly used for utility functions that perform operations related to the class 
          but don't require instance-specific data (e.g., a Math.random()-like function within a custom MathUtils class). 
          Static fields are suitable for storing data that is shared across all instances or represents a fixed configuration.
          
          4. Inheritance:
          Static properties and methods are inherited by subclasses. 
          If a static member is not found in a subclass, 
          the search continues up the prototype chain to the parent class
