Constructors

      In JavaScript, a constructor is a special method within a class or a function used to create and initialize an object instance. 
      Its primary purpose is to set up the initial state of a newly created object by assigning values to its properties.

      Key aspects of JavaScript constructors:
      1. Class Constructors:
      - Within an ES6 class, the constructor method is a special method specifically designed for object creation and initialization.
      - A class can only have one constructor method.
      - It's automatically called when an object is instantiated using the new keyword.
      - The super() keyword can be used within a class constructor to call the constructor of its parent class (superclass).

                class Person {
                  constructor(name, age) {
                    this.name = name;
                    this.age = age;
                  }
                }

                const alice = new Person("Alice", 30);
                console.log(alice.name); // Output: Alice

      Constructor Functions (Pre-ES6):
      - Before the introduction of ES6 classes, constructor functions were the primary way to create and initialize objects.
      - These are regular functions that are intended to be called with the new keyword.
      - The this keyword inside a constructor function refers to the newly created object instance.

                function Car(make, model) {
                  this.make = make;
                  this.model = model;
                }

                const myCar = new Car("Toyota", "Camry");
                console.log(myCar.model); // Output: Camry

      In both cases, the constructor provides a structured way to define how new objects of a particular type are created and prepared for use.
