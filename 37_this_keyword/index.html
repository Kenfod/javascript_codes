This Keyword

      The this keyword in JavaScript refers to the context in which a function is executed. 
      Its value is determined dynamically by how the function is called, rather than where it is defined. 
      This behavior contrasts with many other object-oriented languages where this typically refers to the current instance of a class.
      
      Here are the primary contexts that determine the value of this: 
      
      Global Context:
      When this is used outside of any function or object, it refers to the global object. 
      In a web browser, this is typically the window object; in Node.js, it's the global object.
      
      Method Invocation:
      When a function is called as a method of an object, this refers to the object itself.

                const person = {
                  name: "Alice",
                  greet: function() {
                    console.log(`Hello, my name is ${this.name}`);
                  }
                };
                person.greet(); // 'this' refers to 'person'

      Function Invocation (Non-Strict Mode): 
      In non-strict mode, when a standalone function is called, this defaults to the global object.

              function showThis() {
                console.log(this);
              }
              showThis(); // 'this' refers to the global object (e.g., window)

      Function Invocation (Strict Mode): 
      In strict mode, when a standalone function is called, this is undefined.

              "use strict";
              function showThisStrict() {
                console.log(this);
              }
              showThisStrict(); // 'this' is undefined 

      Constructor Invocation: 
      When a function is called with the new keyword (as a constructor), this refers to the newly created instance of the object.

              function Car(make, model) {
                this.make = make;
                this.model = model;
              }
              const myCar = new Car("Toyota", "Camry"); // 'this' refers to 'myCar'

      Explicit Binding (call(), apply(), bind()): 
      The call(), apply(), and bind() methods allow you to explicitly set the value of this for a function.

              const anotherPerson = { name: "Bob" };
              person.greet.call(anotherPerson); // 'this' refers to 'anotherPerson'

      Arrow Functions: 
      Arrow functions handle this lexically, meaning this is determined by the surrounding scope at the time the arrow function is defined, not when it's called.
      This behavior makes them particularly useful for preserving the this context in callbacks and nested functions.

              const obj = {
                value: 10,
                getValue: function() {
                  setTimeout(() => {
                    console.log(this.value); // 'this' refers to 'obj' due to lexical scoping
                  }, 100);
                }
              };
              obj.getValue();
