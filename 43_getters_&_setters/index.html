Getters & Setters


    In JavaScript, getters and setters are accessor properties that bind an object property to a function that executes when the property is read or written. 
    They allow you to manipulate data behind the scenes while keeping an interface that looks like a normal, direct property access.

    Core ConceptGetter 
    (get): Executes a function when a property is looked up or read. It takes no arguments and must return a value.Setter

    (set): Executes a function when a property is assigned a value. It takes exactly one argument (the value being assigned) and typically returns nothing
